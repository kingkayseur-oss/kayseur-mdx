## 🤖 Présentation

**KAYSEUR-MDX** est un bot WhatsApp multi-appareils construit avec **Node.js** et **Baileys**. Il propose des outils pour gérer les groupes, traiter des médias, utiliser des fonctions d'intelligence artificielle et connecter des sessions WhatsApp.

- **Nom :** KAYSEUR-MDX
- **Version indiquée dans le code :** 22.7.1
- **Préfixe par défaut :** `!`
- **Créateur :** MR KING KAYSEUR THE GLITCH DEV
- **Plateforme :** WhatsApp

## ✨ Fonctionnalités présentes dans le code

### 🔗 Connexion et sessions
- Connexion WhatsApp par QR code.
- Génération de code d'association (pairing code).
- Page web Pairlink pour demander un code et consulter les sessions associées.
- Gestion de plusieurs sessions et reconnexion automatique.

### 👥 Gestion des groupes
- Outils d'administration : ajouter, retirer, promouvoir et rétrograder des membres.
- Paramètres de groupe : ouvrir/fermer, lien du groupe, nom et description.
- Messages de bienvenue et d'au revoir.
- Statistiques de groupe et options de protection (anti-lien, anti-spam et autres réglages).

### 🎵 Médias et conversion
- Outils liés à YouTube et à plusieurs plateformes sociales.
- Fonctions audio/vidéo, conversion et téléchargement selon les services disponibles.
- Création et conversion de stickers.
- Synthèse vocale (TTS).

### 🧠 IA et outils
- Fonctions d'assistance IA avec fournisseurs configurables par clés API.
- Génération d'images via API.
- Traduction, météo, calculatrice, recherche Wikipédia, QR code et autres utilitaires.

### 🧩 Menus et extensions
- Menus de commandes paginés.
- Boutons interactifs lorsque WhatsApp les prend en charge.
- Chargement de plugins JavaScript depuis le dossier `plugins`.

> Les fonctions qui dépendent d'API externes, de clés API, de paquets optionnels ou des droits administrateur peuvent nécessiter une configuration supplémentaire. La présence d'une commande dans le code ne garantit pas que chaque service externe soit disponible à tout moment.

## 🚀 Installation

Prérequis : **Node.js 18 à 22** et npm.

```bash
git clone <URL_DU_DEPOT>
cd <DOSSIER_DU_BOT>
npm install
npm start
```

Configure les variables nécessaires dans un fichier `.env` selon les services que tu souhaites activer, par exemple les clés IA et le numéro propriétaire. Ne publie jamais tes clés API ni tes fichiers de session.
